# 개인정보 비식별화 솔루션 v1.1 (KID)

**KID** (Korean Identifier Detector & masking) — 한국 공공문서의 인명·개인정보를
자동으로 찾아 **검수자가 판단**하고, 가려진 PDF 사본을 만드는 데스크톱 도구입니다.

`hwp · docx · xlsx · pdf · 이미지` 입력 → 개인정보 15종 자동 검출 →
검수(공개 / 가명 / 비공개) → **`<원본명>_마스킹 사본.pdf` 생성**

- **완전 오프라인** — 외부 서버·클라우드 API 없음. 모든 처리가 사용자 PC 안에서 끝납니다
- **무료 · 오픈소스** (GNU AGPL v3) · Windows 10/11 전용
- 개발: 국가기록원 기록연구사 문찬일

---

## 1. 특장점

### 1-1. 폐쇄망에서 그대로 돌아갑니다

공공기관 업무망은 대부분 인터넷이 차단돼 있어, 클라우드 기반 비식별화 서비스를
쓸 수 없습니다. KID는 **설치 패키지 하나(약 681 MB)에 모든 것을 담아** USB로
옮겨 설치합니다. Python 런타임, 의존 라이브러리 45종, 형태소 분석 모델,
Tesseract OCR 엔진(186 MB), 검출 사전까지 전부 포함돼 **설치 중에도 인터넷이
필요 없습니다.**

문서가 외부로 나가지 않으므로, 개인정보를 다루면서 생기는 **자료 유출 위험 자체가
없습니다.**

### 1-2. 한국 공공문서의 실제 모양에 맞췄습니다

범용 개인정보 검출기가 한국 공문서에서 잘 듣지 않는 이유는 형식이 아니라 **문서
구조** 때문입니다. KID는 실무 문서에서 반복적으로 확인된 형태를 직접 다룹니다.

| 실무에서 만나는 모양 | KID의 처리 |
|---|---|
| 명부·대장의 표 — 값만 나열돼 형식으로는 판별 불가 | 표 머리글(`성명·주소·생년월일·계좌번호` 등)을 읽어 **그 열 전체**를 해당 개인정보로 인식 |
| 한글(hwp/hwpx) 표가 한 칸씩 **세로로 풀림** | 세로로 풀린 성명 열도 인식 — 일반어와 형태가 같은 이름(`이재민`), 조사로 오해되는 이름(`이남은`)까지 |
| `홍길동(洪吉童)` 한자 병기 | 괄호 속 한자의 **음이 앞 이름과 맞을 때만** 하나로 묶어 가림 (두음법칙·성씨 관용음 반영) |
| `예금주·계약자·수취인·임차인 ○○○` | 금융·계약 서류의 라벨 21종을 강한 인명 단서로 사용 |
| `고(故) ○○○`, `배우자 ○○○`, `○○○ 외 3인` | 제적·보상 서류 특유의 호칭·관계어 인식 |
| 부분 마스킹된 주민번호 `750302-2******` | 형식이 깨져도 표 맥락으로 회복 |
| 본문은 워드인데 **붙임만 스캔 이미지** | 페이지마다 따로 판정해 붙임·도장 속 개인정보까지 OCR |

**실명 사전 41.7만 명**을 씁니다. 재배포가 허용된 공개 자원만 사용했고
(KLUE 인명, 국가보훈부 독립유공자 명단, 국가기록원 독립운동 판결문 DB),
보훈·제적 기록물의 인명 검출에 직접 기여합니다.

### 1-3. 검수자의 판단을 대체하지 않습니다

KID는 **빠뜨리는 것보다 많이 잡는 방향**(재현율 우선)으로 설계됐습니다. 위양성이
섞이는 대신 놓침을 줄이고, 최종 판단은 사람이 합니다.

- 항목마다 **공개 / 가명 / 비공개** 3정책 중 선택
- **주민등록번호·외국인등록번호·신용카드·휴대전화·계좌번호·여권번호·운전면허번호**
  7종은 변경할 수 없는 **비공개 고정**
- 놓친 부분은 PDF 미리보기에서 **사각형을 직접 드래그**해 보강
- 검출 근거(사전 매치·형태소 태그·표 열 맥락 등)와 신뢰도를 표에 함께 표시해,
  검수자가 왜 잡혔는지 보고 판단할 수 있습니다

## 2. 검출 대상 (15종)

| 분류 | 카테고리 | 기본 결정 |
|---|---|---|
| 인명 | 성명 | 공개 |
| 연락처 | 이메일 · 일반전화 | 공개 |
| 위치 | 주소 | 공개 |
| 신상 | 생년월일 | 공개 |
| 차량·사업자 | 차량번호 · 사업자등록번호 | 공개 |
| **법정 강제 비공개** | 주민등록번호 · 외국인등록번호 · 신용카드 · 휴대전화 · 계좌번호 · 여권번호 · 운전면허번호 | **비공개 고정** |
| 이미지 | 얼굴사진(증명사진) | **비공개** (변경 가능) |

**입력 포맷**: `.hwp` `.hwpx` `.doc` `.docx` `.xls` `.xlsx` `.ppt` `.pptx` `.odt`
`.rtf` `.csv` `.tsv` `.pdf` `.txt` `.html` · 이미지 `.jpg` `.png` `.tif` `.bmp`
`.gif` `.webp` · 압축 `.zip` `.tar` 계열(자동 해제)

## 3. 주의사항 — 도입 전 반드시 확인

> ### ⚠ 검출을 100% 보장하지 않습니다
>
> KID는 검수를 **돕는 도구**이지 대체하는 도구가 아닙니다. 생성된 마스킹 사본은
> **반드시 사람이 눈으로 최종 확인**해야 하며, 누락·오검출에 따른 책임은
> 사용자에게 있습니다. 이 전제 위에서만 사용하십시오.

### 3-1. 검출되지 않는 것

- **외국인 성명** — 한국 성씨 사전·규칙에 기반하므로 `응웬 티 흐엉`, `다나카 하루`
  같은 이름은 자동으로 찾지 못합니다. 외국인등록번호·여권번호는 찾아 주므로 **그
  번호가 나온 자리의 이름을 검수자가 직접 확인**하고 수동 마스킹해야 합니다.
  초청인사 명단처럼 외국인이 섞일 수 있는 문서는 전수 확인이 필요합니다
- **음성·영상 파일** — 마스킹 방식이 완전히 달라 처리 대상이 아닙니다. 업로드 시
  안내창이 뜨고 제외됩니다 (음성은 외부 STT로 전사한 텍스트를, 영상은 캡처
  이미지를 넣으면 검출 가능)
- **저화질 스캔** — 글자가 뭉개진 스캔본은 OCR이 숫자를 잘못 읽어 계좌번호 등을
  놓칠 수 있습니다. 원본 화질이 낮은 문서는 육안 확인이 특히 중요합니다
- **작거나 비스듬한 얼굴 사진** — 정면·일정 크기 이상(A4 기준 대략 19pt↑)이
  대상입니다. 사진이 있는 문서는 미리보기로 확인하고 수동 보강하십시오

### 3-2. 환경 요건

- **Windows 10/11 전용**입니다 (한컴·MS Office COM 자동화를 사용)
- **한글(hwp)·MS Office 문서 변환에는 해당 프로그램이 설치돼 있어야 합니다.**
  없으면 그 문서를 먼저 PDF로 저장한 뒤 넣으십시오. PDF·이미지·txt는 별도 프로그램
  없이 바로 처리됩니다
- 엑셀은 인쇄영역이 지정돼 있어도 전체 시트를 변환합니다(영역 밖 개인정보 누락
  방지). 다만 **숨긴 시트·행은 제외**됩니다 — Excel 자체 특성입니다

### 3-3. 산출물과 원본

- 원본 파일은 **수정하지 않습니다.** 항상 별도의 마스킹 사본을 만듭니다
- 이름이 같은 사본이 이미 있으면 **덮어쓰되 그 사실을 알려 줍니다.** 지정 폴더에
  모아 저장하는 설정에서는 다른 폴더의 동명 문서가 서로 덮어쓸 수 있으니
  주의하십시오
- 처리 과정의 작업 폴더(`.kid`)에는 **검출된 개인정보 원문이 그대로 들어 있습니다.**
  보관 기간을 직접 선택하거나 즉시 정리할 수 있으며, 공용 PC에서는 정리 설정을
  반드시 확인하십시오

### 3-4. 라이선스 — AGPL v3 (중요)

배포 패키지에 **PyMuPDF(AGPL v3)** 와 **PyQt6(GPL v3)** 가 포함되며, KID 코드가
이들과 하나의 프로그램으로 동작합니다. 따라서 **배포물 전체가 AGPL v3 조건**입니다.

| 가능 | 불가능 |
|---|---|
| 무료 배포 · 기관 내 사용 · 수정 | 소스 비공개 배포 |
| 재배포 (동일 조건 + 출처 표시) | 난독화·컴파일로 분석 차단 |
| 기관이 자체 수정해 사용 | 상용 제품에 폐쇄 소스로 편입 |

기관 도입 시 이 조건을 먼저 확인해 주십시오. 자세한 내용은 `LICENSES.md`에 있습니다.

## 4. 사용법

### 4-1. 설치 (한 번만)

1. 배포된 `kid_offline_package.zip`(약 681 MB)의 압축을 풉니다
2. **받은 직후 진본을 확인하십시오** — 명령 프롬프트에서
   ```
   certutil -hashfile "kid_offline_package.zip" SHA256
   ```
   출력된 64자리 값이 함께 받은 `CHECKSUM.txt`와 같아야 합니다
3. `install_offline.bat`을 **마우스 오른쪽 → 관리자 권한으로 실행**
4. 5~10분 뒤 바탕화면에 아이콘이 생깁니다

> 서명 없는 무료 프로그램이라 백신이 막을 수 있습니다. 위 SHA-256이 일치하는지
> 확인한 뒤 허용하십시오.

### 4-2. 검수 — 5단계

| 단계 | 조작 |
|---|---|
| **1. 파일 넣기** | 창에 **드래그 앤 드롭**, 또는 `Ctrl+N`. 여러 개 동시 가능 |
| **2. 자동 검출** | 잠시 기다리면 개인정보가 표로 나타납니다 |
| **3. 검수** | 줄마다 **공개(K) / 가명(P) / 비공개(M)** 선택. `Ctrl`·`Shift`로 여러 줄 선택 후 일괄 적용 |
| **4. 수동 보강** | 놓친 부분은 `[+ 수동 마스킹]` → PDF 위에 사각형 드래그 |
| **5. 사본 생성** | `Ctrl+G` → 원본 옆에 `<원본명>_마스킹 사본.pdf` 생성 후 자동 열기 |

**주요 단축키**

| 키 | 동작 |
|---|---|
| `Ctrl+N` / `Ctrl+Shift+N` | 파일 / 폴더 업로드 |
| `K` `P` `M` `U` | 공개 / 가명 / 비공개 / 미결정 |
| `Shift+라디오` | 범위 선택 + 결정을 한 동작에 |
| `Ctrl+G` | 마스킹 PDF 생성 |
| `Ctrl+O` / `Ctrl+M` | 기존 작업 폴더 / 다중 파일 세션 열기 |

**설정에서 조절할 수 있는 것**

- `🔍 개인정보를 찾는 범위…` — 어떤 카테고리를 찾을지 켜고 끄기
- `🗂 보관 중인 작업 파일…` — 작업 폴더 보관 기간 선택, 즉시 정리

### 4-3. CLI (자동화·대량 처리)

```bash
python scripts/kid.py "C:\문서\안건1.pdf" --with-pdf
```

```bash
python scripts/kid.py "C:\작업폴더\" --recursive --with-pdf
```

주요 옵션

| 옵션 | 설명 |
|---|---|
| `--with-pdf` | PDF로 자동 변환 + 좌표 보강 (PDF 마스킹의 사전 단계) |
| `--recursive` / `-r` | 하위 폴더까지 처리 |
| `--threshold 0.65` | 신뢰도 임계값 (기본 0.55) |
| `--apply-m4` | 처리 후 마스킹 본문 자동 생성 |
| `--undecided mask\|keep` | 미결정 항목 처리 방침 (기본 `mask`) |
| `--no-image-ocr` | 텍스트 페이지 안의 이미지 영역 OCR을 끔 — 빨라지지만 **도장·스캔 붙임 속 개인정보를 놓칠 수 있음** |
| `--dry-run` | 검출만 하고 산출물을 만들지 않음 |

산출물은 `<입력파일명>.kid/<입력파일명>/` 아래에 `extracted.txt`, `positions.csv`,
`audit.json`, `source.pdf` 등으로 생성됩니다. 검수 결정을 반영한 마스킹 PDF는
산출물 폴더를 넘겨 만듭니다.

```bash
python scripts/m6_mask_pdf.py "C:\문서\안건1.kid\안건1" --undecided mask
```

자세한 사용법은 `USAGE.md`, 설치 상세는 `INSTALL.md`를 참고하십시오.

## 5. 기술 구성

| 영역 | 사용 기술 |
|---|---|
| 형태소 분석 | Kiwi (kiwipiepy) |
| 문서 파싱 | pdfplumber · python-docx · openpyxl · olefile · stdlib(zipfile/xml) |
| 변환·마스킹 | PyMuPDF (렌더·좌표 검색·redaction) · 한컴/MS Office COM |

| 얼굴 검출 | OpenCV (headless) |
| 검수 UI | PyQt6 |
| 검출 사전 | 실명 41.7만 · 성씨 · 음절 · 국립국어원 우리말샘 · 법제처 법령용어 · 행정표준코드 기관명 |

Python 3.10+ (배포 패키지는 3.11 기준으로 구성)
